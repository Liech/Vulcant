# Vulcant

Graphic Interface with implementation in Glwf/vulkan1.2 and Godot. slang and imgui is supported.


# Origin

 * I needed something elaborate, but the vulkan api is plain bad
 * Tested AI to do the unbearable boilerplate bonanza
 * Found joy in recreational programming again doing it that way
 * I couldn't decide between Godot and Raw C++

# Current State

 * Im not satisfied with the Graphic Pipeline overall
 * Godot Graphic Pipeline is not ready
 * The Compute Pipeline works quite well on Godot and Vulkan
 * valuable examples exist
 * ImGui works in Vulkan, but not godot yet
